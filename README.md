# Task 6: Host a Static Website with GitHub Pages

## 📌 Project Overview

This project demonstrates how to host a static website publicly using **GitHub Pages**. The website is built with HTML and CSS and deployed directly from a GitHub repository.

The objective is to understand static website hosting, GitHub repository management, and deployment using GitHub Pages.

## 🎯 Objectives

* Create a static website using HTML and CSS.
* Store website source code in a GitHub repository.
* Configure GitHub Pages for website hosting.
* Deploy the website using the `main` branch.
* Make the website publicly accessible for free.

## 🛠️ Technologies Used

* **HTML5** — Website structure
* **CSS3** — Styling and responsive layout
* **Git** — Version control
* **GitHub** — Source code repository
* **GitHub Pages** — Static website hosting

## ⚙️ Deployment Steps

1. Created the `index.html` file containing the website structure.
2. Added CSS styling to improve the website's appearance.
3. Initialized Git and committed the website files.
4. Pushed the source code to the GitHub repository.
5. Opened the repository's **Settings → Pages** section.
6. Selected **Deploy from a branch** as the deployment source.
7. Selected the `main` branch and `/(root)` folder.
8. Saved the configuration and verified the public website URL.

## 🚀 How to Run Locally

Clone the repository:

```bash
git clone https://github.com/Santhosh832/santhosh-devops-portfolio.git
```

Navigate to the project directory:

```bash
cd santhosh-devops-portfolio
```

Open `index.html` in your web browser.
